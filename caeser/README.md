# Caeser Cipher Mechanics & Execution Guide

A lightweight Python implementation of the classic Caeser Cipher built on direct ASCII index manipulation and modular arithmetic ($\mathbb{Z}_{26}$).

Developed by **estriga001** for the **cylab challenge**

---

## How to run

### Prerequisites
* Python 3.x installed on your system.

### Execution
Run the script interactively or import the module in your python environment:

```bash
python3 main.py
